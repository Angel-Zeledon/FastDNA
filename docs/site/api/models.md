# Models and workflows

Models whose output a biologist can act on, the one-call composition of the
whole association pipeline, and the ways a run leaves the interpreter as a
figure or a file.

`SetCoveringClassifier` is the reason this section is not just "use
scikit-learn": its entire learned model is a handful of literal DNA
sequences, each tagged present or absent, which is something you can paste
into BLAST — not an opaque embedding.
